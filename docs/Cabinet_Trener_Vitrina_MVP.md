# MAYAG.fit — Кабінет тренера (вітрина) · MVP · без коду

**Статус:** продуктове ТЗ (екрани)  
**Роль:** тільки **тренер**  
**Принцип:** сайт = вхід через Telegram + вітрина «як мене бачать»; робота = кнопка в бот  
**Не входить:** логін/пароль, клієнт/клуб, розклад/тренування/звіти на сайті

---

## 1. Ланцюжок

```
mayag.fit → Кабінет → Увійти через Telegram
        → (якщо role = coach) Вітрина тренера
        → «Відкрити MAYAG у Telegram» → бот (своє меню)
```

Якщо в базі немає користувача / роль не coach → окремий екран-підказка (див. §4).

---

## 2. Карта екранів (тренер)

| # | Екран | URL (чернетка) | Хто бачить |
|---|--------|----------------|------------|
| A | Хаб «Кабінет» | `/cabinet` або `/kabinet` | усі |
| B | Вхід через Telegram | частина A / модалка | усі |
| C | Вітрина тренера (після входу) | `/cabinet/coach` | лише залогінений coach |
| D | Публічна картка тренера | `/coach/<id>` або `/t/<chatId>` | усі (без логіну) |
| E | «Спочатку бот» / не тренер | `/cabinet/start` | залогінений, але не coach / немає в БД |

На MVP можна об’єднати A+B на одній сторінці.

---

## 3. Екран A — Хаб «Кабінет»

**Мета:** пояснити, що це вітрина, не друга платформа; запропонувати вхід.

**Контент**
- Заголовок: **Кабінет MAYAG**
- Короткий текст:
  - Тренування й робота з клієнтами — у Telegram.
  - Тут — твоя публічна вітрина: як тебе бачать інші.
- Кнопка: **Увійти через Telegram**
- Дрібним: «Немає акаунта в MAYAG? Спочатку відкрий бота» + посилання на бота (існуючий CTA).
- На MVP для тренера: не показувати вибір ролей клієнт/клуб (або сірі «скоро»).

**Немає:** форми телефон / логін / пароль.

---

## 4. Екран B — Після «Увійти через Telegram»

Технічно це крок Telegram Login; з боку UX:

1. Користувач підтверджує доступ у Telegram.
2. Сайт отримує `chat_id`.
3. Шукає користувача в тій же БД, що й бот.

**Гілки**

| Умова | Куди вести |
|-------|------------|
| `role = coach` | → екран C (вітрина) |
| Є в БД, але student / venue_owner | → екран E: «Кабінет цієї ролі ще в розробці» + кнопка в бот |
| Немає в БД | → екран E: «Спочатку заверши реєстрацію в MAYAG у Telegram» + кнопка в бот |
| Відмова / помилка логіну | Повідомлення на A + спробувати знову |

---

## 5. Екран C — Вітрина тренера (головний екран MVP)

**Мета:** «Ось як мене бачать» + швидкий перехід у бот.

### 5.1 Шапка
- Привітання: ім’я з профілю (як у боті).
- Підпис: **Вітрина тренера** · «Публічний вигляд твоєї картки».
- Кнопки:
  1. **Відкрити MAYAG у Telegram** (primary) — той самий принцип, що на сайті зараз.
  2. **Вийти** (з кабінету сайту; Telegram не чіпаємо).

### 5.2 Блок «Як тебе бачать» (прев’ю картки)
Візуально як публічна картка (екран D), дані з профілю тренера:

- Ім’я, прізвище  
- Місто / локація (якщо є)  
- Instagram (якщо є)  
- Типи тренувань (індивідуальні / групові тощо)  
- Заклади «Де треную» (назви; клік → публічна картка закладу *пізніше*, у v1 можна текстом)  
- Документи / освіта — якщо в боті вже публічні для клієнта  
- Короткий статус заповненості (див. 5.3)

Кнопка під прев’ю: **Відкрити публічне посилання** (екран D — щоб скопіювати / шарити).

### 5.3 Блок «Готовність вітрини» (чеклист)
Без редагування на сайті — лише статус + CTA в бот:

| Пункт | Ок, якщо | Якщо ні — підказка |
|-------|----------|---------------------|
| Ім’я в профілі | заповнено | «Доповни в боті: Профіль» |
| Instagram | є | «Додай Instagram у Профілі» |
| Типи тренувань | обрані | «Вкажи типи тренувань» |
| Де треную | ≥1 заклад (для офлайн) | «Прив’яжи заклад» |
| Документи | ≥1 (опційно) | «Додай документи (за бажанням)» |

Кожна «не ок» → кнопка **Виправити в Telegram** (deep link / просто відкрити бота; ідеал — одразу в Профіль).

### 5.4 Блок «Що робити далі в Telegram»
Короткі пункти (не дубль усього меню бота):
- Клієнти та інвайти  
- Розклад і записи  
- Тренування та плани  
- Звіти й розсилка  

Одна кнопка: **Перейти до роботи в Telegram**.

### 5.5 Чого немає на екрані C (свідомо)
- список клієнтів, розклад, звіти, розсилка;
- форми редагування полів на сайті (v1);
- логін/пароль.

---

## 6. Екран D — Публічна картка тренера

**Мета:** те, чим діляться в Instagram / з клієнтом / з клубом. **Без логіну.**

**Контент** (як у боті `pvch_` / картка для клієнта):
- ім’я, місто, Instagram;
- типи тренувань;
- заклади;
- документи (перегляд, якщо дозволено політикою продукту);
- CTA: **Написати тренеру в Telegram** (якщо є username) / **Відкрити MAYAG**;
- CTA для гостя: **Спробувати MAYAG у Telegram**.

**Зв’язок з C:** після логіну тренер бачить прев’ю = те саме, що D.

URL на старті може бути технічним (`/t/<chatId>`); людський slug — пізніше.

---

## 7. Екран E — Немає кабінету / не тренер

**Варіант «немає в БД»**
- Текст: MAYAG працює в Telegram. Спочатку відкрий бота і пройди реєстрацію / інвайт.
- Кнопка: **Відкрити MAYAG у Telegram**
- Посилання назад на головну / кабінет.

**Варіант «є акаунт, але не тренер»**
- Текст: Зараз на сайті доступна вітрина **лише для тренерів**. Твій акаунт — клієнт / заклад.
- Кнопка: **Відкрити MAYAG у Telegram**
- (Опційно) «Кабінети для інших ролей — згодом».

---

## 8. Навігація сайту

Додати в шапку / футер пункт **Кабінет** → екран A.

Існуючі сторінки `coaches.html` (маркетинг «Для тренерів») **не замінюють** кабінет:
- маркетинг = продаж;
- кабінет = вхід + вітрина свого профілю.

З `coaches.html` можна CTA: **Увійти у вітрину** → `/cabinet`.

---

## 9. Тексти CTA (уніфіковано)

| Місце | Підпис кнопки |
|-------|----------------|
| Хаб без логіну | Увійти через Telegram |
| Вітрина (робота) | Відкрити MAYAG у Telegram |
| Чеклист «виправити» | Виправити в Telegram |
| Публічна картка | Відкрити MAYAG / Написати тренеру |
| Немає акаунта | Відкрити MAYAG у Telegram |

Уникати «Увійти в додаток» / «Завантажити».

---

## 10. Дані (логіка, не реалізація)

Джерело тієї ж БД, що бот (`users`, заклади тренера, документи…).  
Ідентифікація після Login Widget: `chat_id` = ключ як у боті.  
Сайт у v1: **читає** профіль; **пише** — ні (редагування в боті).

---

## 11. Критерій готовності MVP (тренер)

- [ ] З mayag.fit можна відкрити Кабінет  
- [ ] Увійти через Telegram  
- [ ] Тренер бачить прев’ю своєї картки + чеклист готовності  
- [ ] Кнопка відкриває того самого бота → своє меню  
- [ ] Публічне посилання на картку відкривається без логіну  
- [ ] Не-тренер / новий юзер бачить зрозумілий екран E  
- [ ] Немає реєстрації логін/пароль на сайті  

---

## 12. Наступні етапи (не зараз)

1. Редагування вітрини на сайті (Instagram, типи, заклади).  
2. Кабінет клієнта / закладу.  
3. Людські URL (`/coach/ivan-petrenko`).  
4. Статистика переглядів публічної картки.

---

**Затвердження:** тільки роль тренер · вхід через Telegram · вітрина read-only · робота в боті кнопкою.
